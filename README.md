# Cybersecurity Foundations – OSINT & Phishing Analysis

## Overview
This repository documents a practical cybersecurity exercise focused on
open-source intelligence (OSINT), phishing detection, metadata analysis,
and basic malware verification.

The work was developed as part of the **Cybersecurity Fundamentals** course.
Original reports and answers are written in Portuguese, as the course was taught in Portuguese.

---

## Objectives
- Apply basic OSINT techniques using open-source tools
- Identify phishing attempts through domain and source validation
- Analyze document metadata to extract relevant information
- Verify executable files using malware scanning platforms

---

## Techniques & Tools
- **Google Dorks** (`site:` and `filetype:`)
- **Metadata analysis** (local file properties and online tools)
- **WHOIS / domain validation**
- **VirusTotal** for malware verification
- Web browser security inspection tools

---

## Work Performed

### OSINT & Information Gathering
- Used Google dorks to locate specific document types within a target domain
- Extracted author and creation metadata from publicly available documents

### Phishing Detection
- Analyzed suspicious emails and redirected domains
- Compared domains with official and trusted sources
- Identified phishing indicators based on domain legitimacy

### Malware Verification
- Downloaded a legitimate executable file from an official source
- Verified file integrity and security using VirusTotal
- Interpreted scan results to assess risk
